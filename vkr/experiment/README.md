# Измеримый эксперимент по оценке трудоемкости

В каталоге `vkr/experiment` размещены воспроизводимые артефакты для количественной оценки гипотезы о снижении трудоемкости разработки при использовании `max-bot-spring-boot-starter`.

## Сценарии

Сравниваются три типовых сценария:

1. `minimal` — минимальный бот с `/help` и эхо-ответом.
2. `security` — бот с командой, защищенной через роль `ADMIN`.
3. `fsm` — бот со сценарием диалога и управлением состоянием.

Для каждого сценария представлены:

- реализация на базе стартера: `examples/src/main/java/ru/maxbot/examples/...`;
- эталонная реализация прямой интеграции с HTTP API MAX: `vkr/experiment/raw-api/...`.

## Измеряемые метрики

- количество файлов исходного кода;
- количество непустых строк кода;
- относительное сокращение количества строк кода при использовании стартера.

## Методика подсчета

Используется скрипт `measure.ps1`, который рекурсивно считает:

- только файлы `*.java`;
- только непустые строки;
- только директории, относящиеся к конкретному сценарию.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\vkr\experiment\measure.ps1
```
